# Results

Generated by the scripts in `src/`; everything here can be regenerated from the
manifests in `data/splits/` and the raw dataset.

| Path | Contents |
|---|---|
| `checkpoints/full.pt`, `head.pt` | Best-validation-macro-F1 checkpoints (state dict, epoch, args, val metrics) |
| `metrics/{full,head}_training.json` | Full training history, hyper-parameters, parameter counts, wall-clock times, train-eval accuracy |
| `metrics/{full,head}_test.json` | One-shot test accuracy, macro-F1, per-class metrics, confusion matrix |
| `metrics/sklearn_*.json` | Validation grid, selected configuration, fit time, test metrics |
| `predictions/*.csv` | Per-image test predictions with confidence and breed names |
| `features/extraction_meta.json` | Frozen-feature extraction time and description |
| `tables/*.csv`, `tables/*.tex` | Dataset counts, results, paired McNemar tests, per-class F1, top confusions, LaTeX tables |
| `figures/*.pdf`, `figures/*.png` | Training curves, confusion matrices, prediction examples |

The report is `report/report.pdf`; compile it with `pdflatex` from the `report/`
directory after running `src/make_report_assets.py`.
